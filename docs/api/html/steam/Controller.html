class Controller

package steam

@:directlyUsed@:allow(steam.Api)

The Steam Controller API. Used by API.hx, should never be created manually by the user. API.hx creates and initializes this by default. Access it via API.controller static variable

Static variables

@:value(65535)staticinlineread onlyMAX_SINGLE_PULSE_TIME:Int = 65535

The maximum duration of a single haptic pulse, in microseconds.

Variables

read onlyMAX_ANALOG_ACTIONS:Int

The maximum number of analog actions steam can recognize. Use this for array upper bounds.

read onlyMAX_ANALOG_VALUE:Float

The maximum value steam will report for an analog action.

read onlyMAX_CONTROLLERS:Int

The maximum number of controllers steam can recognize. Use this for array upper bounds.

read onlyMAX_DIGITAL_ACTIONS:Int

The maximum number of digital actions steam can recognize. Use this for array upper bounds.

read onlyMAX_ORIGINS:Int

The maximum number of origins steam can assign to one action. Use this for array upper bounds.

read onlyMIN_ANALOG_VALUE:Float

The minimum value steam will report for an analog action.

@:value(false)read onlyactive:Bool = false

Whether the controller API is initialized or not. If false, all calls will fail.

Methods

activateActionSet(controller:Int, actionSet:Int):Void

Reconfigure the controller to use the specified action set (ie 'Menu', 'Walk' or 'Drive') This is cheap, and can be safely called repeatedly. It's often easier to repeatedly call it in your state loops, instead of trying to place it in all of your state transitions.

Parameters:

controller

handle received from getConnectedControllers()

actionSet

handle received from getActionSetHandle()

Returns:

1 = success, 0 = failure

action set handle

getAnalogActionOrigins(controller:Int, actionSet:Int, action:Int, ?originsOut:Array<EControllerActionOrigin>):Int

Get the origin(s) for an analog action with an action set. Use this to display the appropriate on-screen prompt for the action. NOTE: Users can change their action origins at any time, and Valve says this is a cheap call and recommends you poll it continuosly to update your on-screen glyph visuals, rather than calling it rarely and caching the values.

Parameters:

controller

handle received from getConnectedControllers()

actionSet

handle received from getActionSetHandle()

action

handle received from getAnalogActionHandle()

originsOut

existing array of EControllerActionOrigins you want to fill (optional)

Returns:

the number of origins supplied in originsOut.

getConnectedControllers():Array<Int>

Enumerate currently connected controllers

NOTE: the native steam controller handles are uint64's and too large to easily pass to Haxe, so the "true" values are left on the C++ side and haxe only deals with 0-based integer indeces that map back to the "true" values on the C++ side

Returns:

controller handles

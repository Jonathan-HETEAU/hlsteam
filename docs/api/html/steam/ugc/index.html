EQueryType

How the items of a Workshop query of all the items are ranked (Steamworks EUGCQuery).

EResult

The result of a Steam operation (Steamworks EResult).

EUserList

The list of items of a user, for a Workshop query (Steamworks EUserUGCList).

EUserListSortOrder

The order of the items of a user list query (Steamworks EUserUGCListSortOrder).

Item

A Workshop item (Steamworks PublishedFileId_t).

ItemState

The state of a Workshop item on the computer (Steamworks EItemState).

ItemUpdate

An update of a Workshop item: set the changes, then submit it (Steamworks UGCUpdateHandle_t).

Query

A query of Workshop items (Steamworks UGCQueryHandle_t): create it with list, userList or details, set its options, send it, read the results with getResult, then close it.

Result

A Workshop item returned by a Query (Steamworks SteamUGCDetails_t).

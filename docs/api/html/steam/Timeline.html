class Timeline

package steam

@:access(steam.TimelineNative)

The Steam timeline of the game recordings (Steamworks ISteamTimeline): game modes, tooltips and events marking the important moments. Times are in seconds, relative to now.

Static methods

@:value({ possibleClip : None })staticaddInstantaneousTimelineEvent(title:String, description:String, icon:String, priority:Int, startOffsetSeconds:Float, possibleClip:ETimelineEventClipPriority = None):TimelineEventHandle

Adds an event at a moment: icon is a Steam icon name (steam_ icons or icons uploaded for the game), priority sorts the overlapping events (0 to 1000), and startOffsetSeconds is relative to now.

@:value({ possibleClip : None })staticaddRangeTimelineEvent(title:String, description:String, icon:String, priority:Int, startOffsetSeconds:Float, durationSeconds:Float, possibleClip:ETimelineEventClipPriority = None):TimelineEventHandle

Adds an event lasting durationSeconds (see addInstantaneousTimelineEvent).

staticclearTimelineTooltip(timeDelta:Float):Void

Clears the description set with setTimelineTooltip.

staticendRangeTimelineEvent(event:TimelineEventHandle, endOffsetSeconds:Float):Void

Ends an event started with startRangeTimelineEvent, endOffsetSeconds relative to now.

staticremoveTimelineEvent(event:TimelineEventHandle):Void

Removes an event.

staticsetTimelineGameMode(mode:ETimelineGameMode):Void

Sets the mode of the game, shown with colors in the timeline.

staticsetTimelineTooltip(description:String, timeDelta:Float):Void

Sets the description shown for the current state of the game in the timeline, from timeDelta seconds relative to now.

@:value({ possibleClip : None })staticstartRangeTimelineEvent(title:String, description:String, icon:String, priority:Int, startOffsetSeconds:Float, possibleClip:ETimelineEventClipPriority = None):TimelineEventHandle

Starts an event whose end is not known yet: end it with endRangeTimelineEvent.

@:value({ possibleClip : None })staticupdateRangeTimelineEvent(event:TimelineEventHandle, title:String, description:String, icon:String, priority:Int, possibleClip:ETimelineEventClipPriority = None):Void

Changes the information of an event started with startRangeTimelineEvent.

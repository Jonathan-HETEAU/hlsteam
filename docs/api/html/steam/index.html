Api

The entry point of the Steam API: call init at startup, then use the functions of this class (achievements, stats, leaderboards, overlay, ownership) and of the other classes of the steam package. The Steam callbacks are run by sync, called automatically by the main loop.

AsyncCall

A pending asynchronous Steam call: its callback is called when it completes, unless it is cancelled.

AvatarSize

The size of an avatar image.

Callback

The callback of an asynchronous Steam call: the result, and true if the call failed.

Changed

The information of a user that changed (Steamworks EPersonaChange), given to the User.requestInformation callback.

ChatMessageType

The type of a lobby chat message (Steamworks EChatEntryType).

Cloud

Steam Cloud: the files of the user stored by Steam and synchronized between computers (Steamworks ISteamRemoteStorage).

ComparisonFilter

A comparison of a lobby list filter (Steamworks ELobbyComparison): how the lobby value compares to the filter value.

Controller

The Steam Controller API. Used by API.hx, should never be created manually by the user. API.hx creates and initializes this by default. Access it via API.controller static variable

ControllerActionSetHandle

A handle of a controller action set.

ControllerAnalogActionData

The state of an analog action.

ControllerAnalogActionHandle

A handle of an analog controller action.

ControllerDigitalActionData

The state of a digital action.

ControllerDigitalActionHandle

A handle of a digital (button) controller action.

ControllerHandle

A handle of a connected controller (Steam Input).

ControllerMotionData

The motion data of a controller.

DistanceFilter

The geographic distance of the lobbies to list (Steamworks ELobbyDistanceFilter).

EControllerActionOrigin

A physical input of a controller bound to an action (Steamworks EControllerActionOrigin). Converts from a number or a name ("XBOXONE_A"), and to its name.

EControllerSource

A source of input of a controller (Steamworks EControllerSource).

EControllerSourceMode

How a source of input is used (Steamworks EControllerSourceMode).

EGamepadTextInputLineMode

The number of lines of the gamepad text input.

EGamepadTextInputMode

The kind of text of the gamepad text input.

ESteamControllerLEDFlags

The flags of Controller.setLEDColor.

ESteamControllerPad

A trackpad of the Steam Controller, for the haptic pulses.

ETimelineEventClipPriority

Whether a timeline event is a good candidate for a clip (Steamworks ETimelineEventClipPriority).

ETimelineGameMode

The mode of the game shown in the Steam timeline (Steamworks ETimelineGameMode).

EventType

The events sent by the native library to Api (handled internally).

FriendFlags
Friends

The friends of the user, the overlay dialogs and the rich presence (Steamworks ISteamFriends).

GameServer

A dedicated game server registered on Steam (Steamworks SteamGameServer), and the list of the servers.

LeaderboardScore

A leaderboard score.

Lobby

A Steam lobby: a group of users sharing key/value data and chat messages, used to gather players before a game.

LobbyKind

The visibility of a lobby (Steamworks ELobbyType).

LobbyListFilters

The filters of Matchmaking.requestLobbyList.

Matchmaking

The lobbies: creation, search and invitations (Steamworks ISteamMatchmaking).

NetworkApi

The callbacks of the peer-to-peer networking, given to Networking.startP2P.

NetworkSessionData

The state of a peer-to-peer session with a user (Steamworks P2PSessionState_t).

NetworkStatus

The error of a peer-to-peer connection (Steamworks EP2PSessionError).

Networking

The peer-to-peer networking between users (Steamworks ISteamNetworking): packets are sent to a user with sendP2P, and received by the NetworkApi given to startP2P.

OverlayKind

A dialog of the Steam overlay, opened with Friends.activateOverlay.

OverlayToStoreFlag

What to do when opening the store page in the overlay (Steamworks EOverlayToStoreFlag).

PacketType

How a packet is sent (Steamworks EP2PSend).

ServerMode

The authentication mode of a game server (Steamworks EServerMode).

SteamNotificationPosition

A corner of the screen where the Steam notifications appear.

Timeline

The Steam timeline of the game recordings (Steamworks ISteamTimeline): game modes, tooltips and events marking the important moments. Times are in seconds, relative to now.

TimelineEventHandle

A handle of a timeline event.

TimelineNative

The native functions of Timeline.

UID

A 64 bits Steam identifier (CSteamID: user, lobby, game server...) or Workshop file identifier, stored as 8 bytes.

User

A Steam user. Users are unique for a UID: get them with fromUID.

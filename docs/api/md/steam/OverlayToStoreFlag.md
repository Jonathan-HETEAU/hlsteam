# steam.OverlayToStoreFlag

**enum abstract** · package [`steam`](README.md) · module `steam.Friends` · source [`steam/Friends.hx`](../../../../steam/Friends.hx)

What to do when opening the store page in the overlay (Steamworks `EOverlayToStoreFlag`).

Underlying type: `Int`

## Values

| Name | Value | Description |
|---|---|---|
| `None` | `0` | Only show the store page. |
| `AddToCart` | `1` | Add the app to the cart. |
| `AddToCartAndShow` | `2` | Add the app to the cart and show the cart. |

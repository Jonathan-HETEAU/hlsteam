# steam.DistanceFilter

**enum abstract** · package [`steam`](README.md) · module `steam.Matchmaking` · source [`steam/Matchmaking.hx`](../../../../steam/Matchmaking.hx)

The geographic distance of the lobbies to list (Steamworks `ELobbyDistanceFilter`).

Underlying type: `Int`

## Values

| Name | Value | Description |
|---|---|---|
| `Close` | `0` | The same region only. |
| `Default` | `1` | The same or nearby regions. |
| `Far` | `2` | About half-way around the globe. |
| `Worldwide` | `3` | No filtering. |
